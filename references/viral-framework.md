# Viral Carousel Framework (4-stage)

Source: `@design.deb` "How to Become a Carousel Genius" framework + Krumzi 2026 + Chris AI Studio synthesis. Cited engagement on reference carousels: 83K likes / 506 comments / 121K saves / 2.3M views per banger; the @design.deb account grew to 154K followers in 7+ years using these structures.

This is the **meta-mental model** that sits above the 5 format types and the 7/10-slide arc — every carousel maps to these 4 stages regardless of format.

---

## A. The 4 stages

| # | Stage | Purpose | Examples of how to execute |
|---|---|---|---|
| **01** | **HOOK** | Capture attention | Bold statement / Contrarian take / Shocking stat |
| **02** | **CONTEXT** | Make people care | Your story / Why this matters / What's at stake |
| **03** | **VALUE** | Deliver the goods | Frameworks / Step-by-step / Lists / Tips |
| **04** | **ACTION** | Convert goodwill | Comment / DM / Follow / Save / Share / Click link |

Default mapping to slide count:

| Slide # | Stage |
|---|---|
| 1 | HOOK |
| 2 | CONTEXT *("confirm on slide 2" rule — this is where most creators lose 30-40% of swipe-through)* |
| 3-9 | VALUE |
| 10 | ACTION |

For 7-slide carousels, compress: 1=Hook, 2=Context, 3-6=Value, 7=Action.

## B. The 4 carousel structures (slide-arc archetypes)

Within the 4-stage framework, these are the **proven slide-arc skeletons**. Pick ONE per carousel.

### 1. PURE INFO — "Straight value. No fluff. Just results."

```
Slide 1   HOOK     — bold claim
Slide 2   CONTEXT  — why it matters
Slide 3-6 VALUE    — key points / steps / tips (one per slide)
Slide 7   RECAP    — quick summary
Slide 8-9 CLIMAX   — the "aha" / non-obvious insight
Slide 10  CTA      — single action
```

**When to use:** Pure tactical content. Reader wants to learn 1 thing fast.
**Examples:** "Best Color Combos in 2026" / "5 typography rules" / "10 viral hook formulas"
**Visual signature:** Each value slide is identical layout (one icon + one line). Numbered prominently.

### 2. STORYTELLING — "Take them on a journey. End with the lesson."

```
Slide 1   HOOK          — "How I [did X]"
Slide 2   SETUP         — context or problem
Slide 3-4 JOURNEY       — struggle, process, challenges
Slide 5-7 TURNING POINT — the shift, what changed
Slide 8-9 LESSON        — what I learned
Slide 10  CTA           — "Save this if it helped"
```

**When to use:** Personal narrative. Author has receipts (numbers, time, scale) to back it up.
**Examples:** "How I got 154K followers in 7 years" / "$1.2K → $42K, what I deleted"
**Visual signature:** Personal photos on Hook + CTA. Narrative-led copy. Numbers prominent on Result slide.

### 3. PROBLEM-SOLUTION — "Agitate, educate, and deliver the answer."

```
Slide 1   HOOK         — pattern interrupt
Slide 2   THE PROBLEM  — make it relatable (audience-language quote works well)
Slide 3-4 WHY IT HAPPENS — root causes
Slide 5-7 THE SOLUTION — framework, steps, or strategy
Slide 8-9 OUTCOME      — the results you can expect
Slide 10  CTA          — DM keyword for the system
```

**When to use:** B2B / consulting / coaching content where you sell a system.
**Examples:** "Why founder businesses stall at $300K" / "Why your carousels don't convert"
**Visual signature:** Slide 2 uses verbatim audience quote. Slides 3-7 use diagrams (problem → cause → solution flow).

### 4. LISTICLE — "List-based content always performs."

```
Slide 1   HOOK        — "10 X you need in 2026"
Slide 2   CONTEXT     — why these matter
Slide 3-8 THE LIST    — tips, tools, strategies, mistakes (one per slide)
Slide 9   BONUS/RECAP — extra item or summary
Slide 10  CTA         — "DM LIST for the full PDF"
```

**When to use:** Save-bait / reference content. Audience wants a callable resource.
**Examples:** "10 design tools" / "12 founder mistakes" / "8 carousel formats"
**Visual signature:** Identical layout per item slide. Save-trigger CTA strong (downloadable resource).

## C. Engagement benchmarks (what "viral" means in 2026)

Per @design.deb's actual carousel insights, viral carousels in this niche hit:

| Metric | Median viral | Top tier |
|---|---|---|
| Views | 2.3M (Instagram + Facebook combined) | 5M+ |
| Likes | 32-83K | 100K+ |
| Comments | 500-3.2K | 5K+ |
| Shares | 26-44K | 60K+ |
| Saves | 39-121K | 200K+ |
| Reposts | 1-2.4K | 5K+ |
| Profile activity | 19-53K | 100K+ |
| Interactions (total) | 250K+ | 500K+ |

**Save-rate benchmark:** Saves ≈ 40-60% of likes is "viral-grade reference content." If saves < 20% of likes, the carousel is engagement-bait, not value content.

**Comment-rate benchmark:** Comments ≈ 1-3% of likes for value content; > 3% = controversy or diagnostic format (Operator Test pattern).

**Profile activity ratio:** Profile activity ÷ views ≈ 2-3% means the hook + brand are working. Below 1% = the carousel got reach but not authority.

## D. The "confirm on slide 2" rule (verbatim from design.deb)

Slide 2 is **NOT** the body — it's the **second hook**.

Pattern: Slide 1 makes a claim. Slide 2 **confirms and amplifies** the claim before introducing context. If you skip the confirm and dive straight to "the problem is X," you lose the swipe.

**Bad (most carousels):**
- Slide 1: *"How to do X"*
- Slide 2: *"Most people fail at X because..."* (introduces problem too fast)

**Good (design.deb pattern):**
- Slide 1: *"How to become a carousel genius"*
- Slide 2: *"I've spent the last 7+ years creating carousels — getting 154K followers in the process. Here's everything I wish I knew before I started."*

The slide 2 confirm sets credibility (receipt) AND pushes the reader deeper. Without the receipt, the hook is empty.

**Required slide 2 ingredients:**
- A specific number (years, followers, revenue, count)
- A first-person stake ("I've", "We've", "My")
- A future-promise tease ("Here's what" / "Here's everything I wish")

## E. Decision tree: structure ↔ format

The 5 format types (`format-types.md`) and the 4 structures cross-reference like this:

| Format | Best structure |
|---|---|
| Comparison | **Pure Info** with side-A vs side-B layout |
| Tutorial | **Pure Info** (steps as value slides) |
| Native | **Storytelling** |
| Compilation | **Listicle** |
| Story | **Storytelling** |
| *(any "why X stalls"/"why most fail")* | **Problem-Solution** |

When unsure, ask the user:
> "Which structure fits the energy of your carousel?
> 1. **Pure info** — straight value, no fluff
> 2. **Storytelling** — journey + lesson
> 3. **Problem-solution** — agitate + deliver the answer
> 4. **Listicle** — list-based, save-bait
>
> If you don't know, just describe the topic in 1 line and I'll pick."

## F. Application checklist

Before approving an outline:

- [ ] **HOOK** is in the 3 archetypes (question / stat / bold) and ≤ 8 words
- [ ] **CONTEXT (slide 2)** confirms hook + delivers receipt (specific number + first-person + future-promise)
- [ ] **VALUE slides** maintain consistent template (one item per slide, identical layout)
- [ ] **ACTION** is single primary CTA (not save + DM + follow at once — pick one)
- [ ] **Structure** picked deliberately (Pure Info / Storytelling / Problem-Solution / Listicle)
- [ ] **Format** picked deliberately (Comparison / Tutorial / Native / Compilation / Story)
- [ ] **Save-rate target ≥ 40% of likes** — content must be reference-worthy

If any checkbox fails, rewrite before HTML generation.
